# ai-report-hipass — 통행료(하이패스) 정리 대시보드

하이패스 통행료 CSV를 업로드하면 **여정(trip) 단위로 자동 정리**해주는 오픈소스 도구입니다.
원본의 일자·금액은 절대 바꾸지 않고, 요금소 게이트 체인을 따라 이동을 묶어
추정 출발지·도착지를 붙여 대시보드로 보여줍니다.

> 🚗 **라이브 데모 (GitHub Pages):**
> <https://leedaham.github.io/ai-report-hipass/viewer.html?load=result>

데모 링크는 가상의 샘플 데이터(`data/sample/`)를 자동으로 불러와 대시보드를 바로 보여줍니다.

---

## 기능

- **하이패스 원본 CSV** 업로드 → 거래를 여정 단위로 그룹핑
- **동선 지식 베이스**를 참고해 추정 출발지·도착지 부여
- **대시보드**: 주차별·일자별·경로별 통행료 차트, 최근 여정, 여행별 집계
- **상세 내역**: 여정 그룹 펼치기/접기, 검색·필터·정렬
- **요약**: 동선별·여정별·주차별·일자별 합계

## 디렉토리 구조

```
.
├── viewer.html              # 대시보드 뷰어 (단일 HTML, 외부 의존성 없음)
├── data/
│   ├── sample/              # 공개용 가상 데모 데이터 (커밋됨)
│   │   ├── sample-toll.csv    # 가상 하이패스 원본
│   │   ├── sample-route.csv   # 가상 동선 지식 베이스
│   │   └── sample-result.csv  # 가상 처리 결과
│   └── private/             # 로컬 전용 실제 데이터 (git 무시)
│       ├── toll/            # 실제 원본 CSV
│       ├── route-data.csv   # 실제 동선 지식 베이스
│       └── results/         # 실제 처리 결과

```

## 데이터 포맷

### 1. 원본 하이패스 CSV (`data/private/toll/`)
하이패스 홈페이지에서 내려받은 CSV를 그대로 사용합니다.
파일 상단의 설명 블록(사용기간·전체건수·합계)은 그대로 두고,
`번호`로 시작하는 행이 실제 헤더입니다.

핵심 컬럼: `거래일시`, `입구`, `출구`, `청구금액`, `납부할통행료`, `비고`

> ⚠️ `청구금액`은 콤마가 포함된 쿼트 문자열(`"9,200"`)이라
> 단순 콤마 분할 대신 정식 CSV 파서를 사용해야 합니다.

### 2. 동선 지식 베이스 (`data/private/route-data.csv`)
사용자의 주 이동 경로를 기록한 테이블입니다.

| 컬럼 | 설명 | 예 |
|---|---|---|
| 동선ID | 고유 키 | `DT-AM` |
| 동선명 | 사용자가 이해하는 이름 | `출퇴근(아침)` |
| 추정출발지 | 출발 장소 | `집(천안 두정)` |
| 추정도착지 | 도착 장소 | `회사(대전 중구)` |
| 경로패턴 | 게이트 이동 순서 (`→` 연결) | `서천안→신탄진→남대전` |
| 시간대 | 전형적 시간대 | `07~08` |
| 방향 | `왕복`/`편도` | `왕복` |
| 비고 | 특이사항 | `월~금` |

### 3. 결과 CSV (`data/private/results/`)
원본 거래 1건당 1행이며, 여정 정보를 컬럼으로 추가합니다.
`몇월몇주차`·`일자`·`통행료`·`입구`·`출구`는 원본 그대로(불변)이고,
`여정ID`·`동선명`·`추정출발지`·`추정도착지`는 AI가 추정한 값입니다.

## 사용법

1. **viewer.html**을 브라우저에서 엽니다.
2. 처리 결과 CSV(`data/private/results/*.csv`)를 끌어다 놓거나 클릭해 선택합니다.
   원본 하이패스 CSV도 바로 열어 확인할 수 있습니다.
3. 대시보드·상세·요약 탭에서 통행료를 분석합니다.

GitHub Pages 배포 시:
- `?load=result` → 샘플 결과 데이터 자동 로드
- `?load=toll` → 샘플 원본 데이터 자동 로드

## 프라이버시

실제 통행료·동선 데이터(집·회사 위치 등)는 **개인 정보**이므로
`.gitignore`로 추적에서 제외하고, 레포에는 **가상 샘플 데이터만** 올립니다.
직접 사용 시 `data/sample/` 대신 자신의 데이터를 `data/private/toll/`, `data/private/route-data.csv`,
`data/private/results/`에 넣어 로컬에서 사용하면 됩니다.
